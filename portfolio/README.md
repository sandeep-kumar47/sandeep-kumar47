# Sandeep Kumar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- Accessible navigation with a mobile menu
- Sections for introduction, about, learning skills, projects, and contact
- Custom code-card illustration and project previews built with CSS/HTML
- Reduced-motion preference support
- Dynamic footer year
- No location or personal website URL displayed

## Files

- `index.html` — page structure and content
- `style.css` — layout, visual design, and responsive styling
- `script.js` — mobile navigation and footer year

## Run locally

1. Download or clone this repository.
2. Open the `portfolio` folder.
3. Open `index.html` in a browser.

No build tools or package installation are required.

## Customize

Update the text in `index.html` as your skills and projects grow. Add links to real project repositories once they are published. The skills section intentionally describes technologies as learning areas.

## Deploy

This project can be published with GitHub Pages after configuring Pages to serve the repository content. Since these files are in the `portfolio/` folder of the profile repository, a simple option is to move them to a dedicated repository when repository-creation access is available.
